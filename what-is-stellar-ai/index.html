01 · App

Main workspace

The app is where users ask Stellar AI to chat, code, debug scripts, improve websites, create plans and continue work in one place.

02 · Credits

Usage meter

Credits show how much AI capacity is available. Free credits help people try it; paid credits and top-ups keep serious users working.

03 · Plans

Upgrade path

Plans are for people who need more monthly credits, stronger models, bigger tasks and more serious project capacity.

04 · Settings

Control room

Settings is where users manage account, billing, credits, preferences, voice, models, plugins, support and privacy.

05 · Script tools

Google entry pages

Script pages bring in FiveM, QBCore, ESX, ox_inventory and Roblox users from search, then send them into the app.

06 · Billing

Pay only when needed

Users should start free, see value, then pay when extra credits or stronger models save them time.
