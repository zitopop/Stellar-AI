6. Jarvis, StellarX, plugins and connected computers

Jarvis is an assistant interface inside Stellar. Plus currently unlocks Jarvis Voice + Vision; Pro adds Jarvis Pro briefings and proactive alerts. The separate private owner phone-calling and administration controls are not customer plan benefits.

The Jarvis Computer module opens StellarX Work Agent. During the current beta, direct StellarX Work Agent availability may be broader than paid Jarvis access. A user must pair their own Windows companion before PC actions can run.

Connected-computer actions are limited by account permissions and local companion safeguards. Read-only inspection can run where enabled; file writes, terminal commands, URL opening, mouse clicks, keyboard shortcuts and typed text remain subject to the permissions and approval flow shown in the product. Shell access and mouse/keyboard control are off by default. Users can disconnect a PC or use Emergency Stop to stop queued or active PC-agent work.

Hard blocks are designed to prevent access to Windows system directories, credential/key stores, browser-secret stores, destructive disk or security-disabling commands, and other sensitive operations. These safeguards reduce risk but do not make computer automation risk-free. Keep backups and review actions before approval.

StellarX and connected tools are only for accounts, files, computers and services that users own or are authorised to control. Do not use Stellar to access someone else’s account or device, bypass security, send spam, create malware, scrape private data without permission, steal credentials or perform harmful activity.
