The plugin can only access approved Roblox services. It cannot read your Windows passwords, browser cookies, API keys or files on your PC.

3. Tell Stellar what to make

Example: “Build a full Roblox obby map with spawn, platforms, checkpoints, lava, neon signs and a finish area.” Stellar inspects first, then can create real map geometry in Workspace after you approve it.

Safety

Read-only inspection can run without edit approval. Creating or changing Roblox scripts, folders and remotes requires you to select and approve those actions. Studio Change History waypoints are created so edits can be undone.
