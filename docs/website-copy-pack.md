### Ship-this-week checklist (source)

1. Pick one script or site job that must ship this week.
2. Paste the error, brief, or broken file into Stellar.
3. Apply the fix or accept the generated scaffold.
4. Test once in-game or on staging.
5. Ship, then book the next job (or upgrade if you hit free limits).
