Why Stellar

Specialised enough to be useful.

Generic AI can write Lua. Stellar is designed around the workflow of actually shipping and maintaining Roblox and FiveM projects.

Project-shaped output

Workflow

Four steps from brief to better build.

01 — Describe

Give Stellar the job.

Explain the system, framework, constraints and what you already have.

02 — Generate

Get organised files.

Stellar produces the relevant project files instead of only a loose code block.

03 — Test

Run it privately.

Review dependencies, permissions and server-side checks before production.

04 — Improve

Bring back what changed.

Fix errors, tune behaviour and extend the system without starting from zero.
