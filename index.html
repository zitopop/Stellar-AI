PROMPT

Build a secure QBCore server event that gives an item only after validating the player and reward amount.

Example preview · server validation shown intentionally.
server.lua · QBCore
local QBCore = exports['qb-core']:GetCoreObject()

RegisterNetEvent('stellar:reward', function(amount)
  local src = source
  local Player = QBCore.Functions.GetPlayer(src)
  if not Player then return end

  amount = tonumber(amount)
  if not amount or amount < 1 or amount > 5 then return end
  Player.Functions.AddItem('repairkit', amount)
end)

StellarX is the work layer for bigger tasks involving code, files, approved computer actions and connected tools. Important actions stay reviewable.

Each plan includes a usage allowance. The app shows how much remains and when it resets. Heavier models and longer tasks can use the allowance faster.

Yes. Paid users can manage or cancel the subscription from billing settings. Cancellation stops the next renewal and access normally continues to the end of the paid period.
