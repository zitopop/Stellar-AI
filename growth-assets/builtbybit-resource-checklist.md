# BuiltByBit resource compliance checklist

BuiltByBit's current resource rules prohibit using a resource primarily to distribute external links or ads. A BuiltByBit upload therefore needs to contain the actual working resource and should not be treated as a link-farm for Stellar AI.

For a compliant free resource:

- upload the functioning files themselves;
- use an accurate category and description;
- do not place off-site purchase prompts or advertising inside the resource;
- disclose required dependencies in the dependencies section;
- avoid bump-only updates;
- use only content you have the right to distribute;
- verify the current rules immediately before publishing.

This channel should be used to build reputation with genuinely useful resources, not automated promotional spam.
