Roblox ProximityPrompt Not Firing? Fix Trigger Problems

A ProximityPrompt can fail because it is disabled, parented wrong, blocked by distance/line of sight, handled on the wrong side or missing a RemoteEvent handoff.

Fast diagnosis

Check whether the prompt appears first. If it appears but code does not run, trace the Triggered event and whether the script is a Script or LocalScript.

Common causeThe prompt is inside an object that is not in Workspace or the script listens on the wrong instance.
Safe fixAttach the prompt to a visible part, listen to Prompt.Triggered and print the player parameter.

Fix checklist

  • Confirm Enabled is true and MaxActivationDistance is sensible.
  • Check the prompt is parented to a part or attachment in Workspace.
  • Use server Script for authoritative rewards.
  • Use RemoteEvents only for UI effects that need the client.
