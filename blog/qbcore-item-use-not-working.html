If an item appears in inventory but does nothing when used, check item registration, inventory framework, event direction and server/client responsibility.

Fast diagnosis

The most common issue is that the item exists in shared items but is never registered as usable, or the callback calls a missing client event.

Common causeThe item name in shared items does not match the item name registered as usable.
Safe fixRegister the exact item key once, then trigger a minimal client event and log both sides.

Fix checklist

  • Compare item name spelling across shared/items.lua, inventory data and server code.
  • Check whether your inventory uses qb-inventory, ox_inventory or another bridge.
  • Log the usable callback before triggering the client event.
  • Avoid giving rewards client-side after item use.
