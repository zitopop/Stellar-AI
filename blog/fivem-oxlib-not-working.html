ox_lib not working? Fix the dependency before blaming the script.

When ox_lib menus, notifications or callbacks do not work, the issue is usually resource order, manifest setup, import syntax or a missing shared script line.

Fix it with Stellar AI →

1. Start ox_lib before dependent resources

Place ensure ox_lib above resources that use lib functions. If your script starts first, lib may be nil or missing required exports.

2. Check fxmanifest shared scripts

Many ox_lib setups need the init import in shared_scripts before your client or server code uses lib. Confirm the path matches your installed version.

3. Match client and server usage

Some lib features are client-only and some are server-side. Use menus and notifications in the correct context and avoid calling UI functions from server files.

4. Watch for old snippets

Old forum snippets may use outdated calls or assume a different framework. Keep the minimal ox_lib example working before adding QBCore logic.

5. Give AI the full load context

Paste the error, manifest, resource order and exact lib call. Without those, an AI debugger may patch the wrong file.
