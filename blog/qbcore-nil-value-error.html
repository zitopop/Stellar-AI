QBCore nil value error? Find what is nil before changing random code.

Attempt to index a nil value means the script expected a table or object but got nothing. In QBCore that often comes from missing player data, wrong exports, dependency order or config names.

1. Start with the exact line

Copy the full server/client error and inspect the named file and line. Check the object before the dot or bracket; that is usually the nil value.

2. Check QBCore export timing

If QBCore is nil, confirm qb-core starts before your resource and that your GetCoreObject call matches your framework version.

3. Validate player data exists

PlayerData can be empty until login/spawn events finish. Read it after the correct QBCore player-loaded event or fetch server-side data safely.

4. Confirm config keys exist

A misspelled Config item, job name, grade, item or location table can produce nil errors even when the framework is fine.

5. Protect server callbacks

Never trust client data. If a player, item, job or account lookup can fail, handle that failed lookup before indexing into it.
