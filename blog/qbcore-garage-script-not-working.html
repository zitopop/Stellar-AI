Fast diagnosis

Trace one vehicle from database row to spawn event to entity creation. If the plate or citizenid changes at any step, the garage cannot reliably find the car.

Common causeThe plate in the database has spaces/case differences from the spawned plate.
Safe fixNormalize plates and update vehicle state server-side when storing/spawning.

Fix checklist

  • Confirm only one garage resource is active.
  • Check owned_vehicles/player_vehicles schema expected by your framework.
  • Print citizenid, plate, state and garage name during spawn.
  • Validate spawn coordinates are clear and valid.

What to test before going live

Store one vehicle
Restart resource
Spawn the same vehicle
Check state changes
Try a second garage
