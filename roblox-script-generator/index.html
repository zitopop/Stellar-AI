Common mistakes to avoid

Trusting the client

Do not let a LocalScript decide final prices, rewards, permissions or damage. Treat client input as a request for the server to validate.

Skipping placement notes

Code can be syntactically correct and still fail because it lives in the wrong Roblox Studio service or script type.

Regenerating everything

When one line fails, keep the working structure and ask for a focused repair. This makes regressions easier to spot.

Publishing without testing

Use a private test place and exercise failure cases, mobile input, repeated actions and player disconnects before release.
