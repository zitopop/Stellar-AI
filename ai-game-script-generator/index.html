What a useful AI game script generator should return

Project structure

For FiveM, that can mean fxmanifest.lua, client.lua, server.lua and config.lua. For Roblox, it can mean server Scripts, LocalScripts, ModuleScripts and RemoteEvents with exact Studio placement.

Server authority

Currency, inventory, rewards, permissions and persistent state should be decided by the server. Generated client code should request actions rather than decide sensitive outcomes.

Install and test steps

The answer should explain dependencies, file locations, setup order and a small checklist you can run before putting the system on a live server or published game.

Use a different brief for Roblox and FiveM

Roblox Studio and FiveM both use Lua-family languages, but their project structures are different. A Roblox request should name the relevant services and where Scripts, LocalScripts and ModuleScripts belong. A FiveM request should name QBCore, ESX, Qbox or standalone, plus inventory, target, menu and database dependencies.

Roblox example

Ask for a server-owned coin pickup, the RemoteEvent or shared module layout if needed, the exact Studio containers, and tests for two players touching the same pickup.

FiveM example

Ask for a small job interaction with a server-validated reward, configurable location, dependency list, fxmanifest and tests for repeated or invalid requests.

Debug the smallest failing part

After testing, bring back the exact error and the affected file instead of regenerating the whole project. Include what you expected to happen, the framework or service version, and any dependency you changed. Keeping working files intact makes regressions easier to spot.
