QUESTIONS

What Server Pass is—and is not.

Does Server Pass mean zero limits?

No. The pilot removes the normal free daily Discord counter for activated guilds, but provider capacity, abuse protection, input-size limits and safety controls still apply.

Does Stellar execute generated code on my live server?

No. The bot returns code and debugging guidance for a developer to inspect. Test changes on a development or staging server before production deployment.

Are private API keys supposed to be pasted into Discord?

No. Do not paste passwords, API keys, database credentials, payment details or recovery codes into Discord prompts.
